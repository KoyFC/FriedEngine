# Starting a game

`fried.Bootstrap.run()` is a whole `main` for a game made the editor's way: it opens a window of the size `display` in `project.fried` names, creates the renderer, registers the game's nodes and every file in `assets/scenes` under its file name, and loads the scene named by `startScene` (the first one, by name, when there is none). A game that needs more extends `fried.Game`, with `start()`, `sceneLoaded(context, scene)`, `update(delta)` and `shutdown()` hooks, and passes it in, which is where a second window or a global such as a saved score goes. `sceneLoaded` runs for every scene file the game loads, once it is on screen, and is where code adds what the file cannot hold, such as a node made in code or an input handler. The nodes are the `@:serializable` classes in the game's `nodes` package, found by the macro `NodeDiscovery`, so there is no list to keep. The size, scene names and start scene are read from `project.fried` at compile time, like `Project.name()`.
